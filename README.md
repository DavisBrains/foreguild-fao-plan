# Foreguild FAO operating plan

This is an independent contest entry by **David Lorwen** (`@Davis_Brains`) for Seer’s Foreguild FAO Operating Plan Contest ([poidh Base #1531](https://poidh.xyz/base/bounty/1531)).

## Live pages

The plan is at https://davisbrains.github.io/foreguild-fao-plan/ and the PDF is at https://davisbrains.github.io/foreguild-fao-plan/foreguild-fao-operating-plan.pdf. The claim image is at https://davisbrains.github.io/foreguild-fao-plan/claim.png. The demo source lives in [demo/](./demo/), and you run it with `cd demo && python3 run_demo.py`.

## What is in the plan

It is a revenue first FAO design. Bonded Outcome Guilds clear accepted outcomes, futarchy on Seer (Gnosis) scores policy on CMV₉₀, and settlement happens on Base. It includes an interactive calculator and a demo of the T0 harness and mandate compiler. Assumptions are labeled and sourced benchmarks are linked.
